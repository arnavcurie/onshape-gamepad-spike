Type each mate name exactly as Onshape reports it, then press Initialize — it checks the mate exists, is drivable, reads its limits, and fills Actual from the model. Press it again after driving and it also reports any joint that did not move where it was told. Editing a name marks the table dirty and you must Initialize again. Several rows may use the same input — give each its own mate and Scale, so one control can drive two joints in opposite directions. Hold LB to move anything. LB+Back homes, LB+Start re-initializes. Sticks integrate as speed; triggers map straight onto the joint's range.
